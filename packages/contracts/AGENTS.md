# Спільні контракти

Zod 3-схеми запитів і відповідей між web, API та (за форматом) плагіном.
Файли за доменами: `auth`, `applications`, `admin`, `discord`, `minecraft`;
усе реекспортується з `src/index.ts`.

- Лише transport-схеми й типи з них. Не імпортуй код web/API, Drizzle,
  Fastify, Next.js чи секрети — пакет потрапляє й у браузер.
- Не експортуй DB-модель і внутрішні ідентифікатори.
- Нове поле відповіді додавай як необов'язкове або з `.default(...)`, щоб
  старий вебклієнт і нова версія API працювали разом. Несумісну зміну
  супроводжуй оновленням усіх споживачів і порядком розгортання.
- Пакет публікує лише `dist`; Turborepo збирає його перед залежними
  пакетами. Після змін запускай з кореня `pnpm typecheck` і `pnpm test`.
- Зміна формату Minecraft-команд потребує оновлення
  `apps/minecraft-plugin` і нової версії JAR.

Документація: Zod 3 — https://v3.zod.dev (не плутай з Zod 4 на
https://zod.dev).
