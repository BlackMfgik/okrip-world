# Короб 7.62×54R у чохлі Multicam

3D-модель кулеметного короба: пластиковий торець із пружинною кришкою та планкою кріплення, м'який корпус із кордури Multicam, ручка зі стропи, блискавка по спинці.

| Файл | Що це |
| --- | --- |
| `ammo-box.glb` | Готова модель (метри, PBR-текстури) для Blender, Unity, Unreal, веба |
| `model.js` | Параметричне джерело на three.js, розміри в мм (`H`, `W`, `D`, `R` на початку файлу) |
| `index.html` | Переглядач: обертання, положення «стоїть/лежить», відкриття кришки |

Габарити: 250 × 104 × 151 мм (без ручки та кріплення).

Переглядач вантажить three.js з jsDelivr, тому відкривайте його через будь-який локальний сервер, наприклад `npx serve models/ammo-box`.
